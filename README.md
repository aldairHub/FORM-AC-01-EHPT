# FORM-AC-01 — Análisis de caso: fallo real en un sistema distribuido

## Contexto
Este repositorio corresponde a la actividad formativa **FORM-AC-01: Análisis de caso de un fallo real en un sistema distribuido** (Semana 3, 9–15 de noviembre de 2026).

El objetivo es analizar un incidente real documentado en un informe post-mortem para identificar qué falló, por qué falló, cuál fue su impacto y qué lecciones pueden aplicarse al proyecto fin de curso (PFC). Esta actividad es preparatoria para:
- **EXP-1** (Exposición del 1.er corte, Semana 4)
- **TA-PFC-E1** (Entrega 1 del Proyecto Fin de Curso, Semana 5)

> **Nota:** Actividad de carácter formativo (sin calificación). Su entrega completa es requisito para presentar EXP-1 y TA-PFC-E1.
